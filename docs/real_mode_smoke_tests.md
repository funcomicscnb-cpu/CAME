# Real-Mode Smoke Tests

Stage 15 adds optional smoke validation for the Stage 5/6 omics layer. The tests
check whether external real-mode tools are detectable and, when a tiny compatible
toolchain is available, run minimal RNA-seq and ATAC-seq command-level checks.

These tests do not replace stub-mode tests and do not require full biological
datasets, large references, or phenotype-specific assumptions.

## Required Tools

The inventory script checks:

- FastQC
- MultiQC
- STAR
- featureCounts
- bwa
- samtools
- bedtools
- Java
- `HMMRATAC`, `hmmratac`, or a HMMRATAC jar

RNA direct smoke requires FastQC, STAR, and featureCounts. ATAC direct smoke
requires FastQC, bwa, samtools, and bedtools. MultiQC is needed only for the
optional RNA Nextflow real-mode smoke.

## Soft And Strict Modes

Soft mode is the default:

```bash
bash tests/test_real_mode_smoke.sh --soft
```

Missing real-mode tools are recorded as warnings and unavailable execution paths
are skipped.

Strict mode fails if required tools for the requested real-mode smoke paths are
missing:

```bash
bash tests/test_real_mode_smoke.sh --strict
```

HMMRATAC is required for strict ATAC validation. In soft mode, a missing
HMMRATAC command or jar is reported as a warning and no HMMRATAC peak call is
attempted.

## Generate Smoke Data

Generate deterministic tiny fixtures:

```bash
python3 bin/make_real_mode_smoke_data.py --outdir assets/test_data/real_mode_smoke
```

The generator writes uncompressed FASTQ files, a tiny FASTA, a minimal GTF,
chromosome sizes, a BED helper, `omics_samplesheet.csv`, and
`reference_manifest.tsv`. STAR and bwa indexes are not generated by default; the
smoke test creates them in a temporary directory when those tools are available.

## Tool Inventory

Run the detector directly:

```bash
python3 bin/check_real_mode_tools.py --outdir results/real_mode_smoke --mode soft
```

The output table is:

```text
results/real_mode_smoke/tool_check.tsv
```

Rows use `PASS`, `WARNING`, or `ERROR` severity. The script does not install
tools.

## RNA Real-Mode Smoke

When FastQC, STAR, and featureCounts are available, the shell test runs:

- FastQC on one tiny RNA FASTQ
- STAR genome generation against the tiny FASTA/GTF
- STAR alignment for one read set
- featureCounts against the tiny aligned BAM

When MultiQC is also available, the test attempts a tiny RNA-only Nextflow
real-mode run with `--run_stage bulk_omics`, `--omics_stub false`, and
`--omics_types rnaseq`.

## ATAC Real-Mode Smoke

When FastQC, bwa, samtools, and bedtools are available, the shell test runs:

- FastQC on one tiny ATAC FASTQ
- `bwa index` and `bwa mem`
- `samtools view`, `sort`, `index`, and `quickcheck`
- `bedtools coverage` over a tiny BED interval

HMMRATAC is resolved but not biologically peak-called on the tiny fixture.

## HMMRATAC Jar Handling

HMMRATAC resolution follows the Stage 5 ATAC-seq real-mode order:

1. `HMMRATAC` on `PATH`
2. `hmmratac` on `PATH`
3. `$CAME_HMMRATAC_JAR`
4. `--hmmratac_jar` or `--hmmratac-jar`
5. local jar names such as `HMMRATAC.jar`, `hmmratac.jar`,
   `tools/HMMRATAC.jar`, `environment/tools/HMMRATAC.jar`, or
   `environment/HMMRATAC.jar`

Java must be available when HMMRATAC is resolved through a jar.

## CI Policy

Default CI remains stub-mode focused. Real-mode smoke validation is optional and
manual because hosted runners do not install heavy bioinformatics tools or large
reference assets by default.

The manual workflow dispatch job runs the soft smoke test as an inventory and
skips unavailable execution paths.

## Troubleshooting

If soft mode skips a path, inspect `tool_check.tsv` first. Install the missing
tool externally, activate the intended environment, and rerun the smoke test.

If STAR fails during genome generation, confirm the FASTA and GTF were generated
together by `bin/make_real_mode_smoke_data.py` and remove any stale generated
index directory before rerunning.

If strict ATAC validation fails on HMMRATAC, place a valid jar at one of the
documented paths, set `CAME_HMMRATAC_JAR`, or expose `HMMRATAC`/`hmmratac` on
`PATH`.
